# Контракт демонстрационного приложения

* Скидка: 0 при сумме ниже 120; 10 при сумме 120 и выше.
* Проверка результата поиска: verified имеет тип bool. Без ✅ — False, с ✅ — True.
* Cart.total(unit_price, quantity) возвращает произведение цены и количества.
* invoice_total(amount, fee) — async-функция, возвращающая amount + fee.
* Возврат денег: удержание комиссии должно быть уточнено с владельцем продукта.
* is_nonnegative(0) возвращает True. stable_token() по исходному контракту возвращает 0.

Это специально подготовленное учебное приложение. Известные мутации в demo/* —
материал демонстрации, а не реальные дефекты сторонних проектов.
